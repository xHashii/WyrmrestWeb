Wowhead item stat tooltip — front-end preview

This shows exactly how the gear tooltip renders once includes/wowhead.php has fetched and cached a tooltip from Wowhead. The first two stat blocks are verbatim nether.wowhead.com/wotlk/tooltip/item/<id> tooltip markup — the JSON tooltip API the Wowhead sites themselves use, which returns only the tooltip (never the item page) — sanitised the same way the server does: quality q0–q7 classes kept, the money*/socket-* tokens behind Wowhead's coin and gem icons kept, internal <!--stat7-->-style markers and every inline attribute dropped, relative Wowhead links made absolute, and the title row's Phase N marker removed. The third block is hand-built to exercise every socket colour (meta, prismatic, cogwheel). In the live app each block is injected by getWowheadItemTooltips() into includes/equipment-slot.php.
