Wowhead item stat tooltip — front-end preview

This shows exactly how the gear tooltip renders once includes/wowhead.php has fetched and cached a tooltip from Wowhead. The stat blocks below are verbatim nether.wowhead.com/wotlk/tooltip/item/<id> tooltip markup — the JSON tooltip API the Wowhead sites themselves use, which returns only the tooltip (never the item page) — sanitised the same way the server does: quality q0–q7 classes kept, internal <!--stat7-->-style markers and every inline attribute dropped, relative Wowhead links made absolute. In the live app each block is injected by getWowheadItemTooltips() into includes/equipment-slot.php.
