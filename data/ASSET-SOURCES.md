# Armory visual data sources

`item-icon-names.json` maps the icon FileDataIDs used by the already bundled
3.4.3 Item and ItemAppearance CSVs to their icon basenames. It contains filenames,
not image data, and is generated by `tools/build-item-icons.py`.

Source: [wowdev/wow-listfile](https://github.com/wowdev/wow-listfile),
`parts/interface.csv`, revision
`53b0656481b4a72f4cefb5851f4b38bea94b293c` (September 8, 2026).
Only `Interface/Icons/*.blp` names referenced by this project's client exports
are retained. The source listfile itself is not bundled.

The small local PNG icon set is documented in `images/items/README.md`. Remote
icons and optional model-viewer data are served by Wowhead/ZAM. World of Warcraft
artwork belongs to Blizzard Entertainment. The SVG empty-slot outlines are
original UI fallback shapes in this project; they never stand in for invented
item identities or statistics.
